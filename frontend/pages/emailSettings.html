Gmail Setup Guide
  • 1 Open your .env file in backend/ and set EMAIL_USER to your Gmail address.
  • 2 Generate a Gmail App Password — go to myaccount.google.com/apppasswords. You need 2-Step Verification enabled.
  • 3 Set EMAIL_PASS in .env to the 16-character App Password (no spaces).
  • 4 Restart the backend server so it picks up the new environment variables.
  • 5 Fill in the form below, click Save Settings, then Send Report Now.
